# jenkins-chatops

Trigger Jenkins builds and check build status from Slack or Discord chat commands.

This is my Sem 1 OJT open source project (PST_OSS_036). The idea is simple: instead of opening the Jenkins dashboard every time, you type a command in chat like `/build my-job` and the bot talks to Jenkins for you.

## Plan

- Connect a Slack/Discord bot to Jenkins
- `/build <job>` to start a build
- `/status <job>` to check if the last build passed or failed

## Status

Just getting started. Learning the pieces first: Git, Jenkins basics, then the bot.
